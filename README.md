# sense the tense

карточная браузерная игра для тренировки английских времён на примерах из живых ситуаций.

игра позволяет выбрать нужные времена, темы и количество карточек. прогресс и карточки для повторения сохраняются в браузере на текущем устройстве.

## онлайн-версия

https://sense-the-tense.galkina-a-97.chatgpt.site

## запуск проекта

```bash
npm install
npm run dev
```

## проверка сборки

```bash
npm run build
```

## автономный html-файл

```bash
npm run build:offline
```

готовый файл появится в корне проекта под именем `Sense the Tense.html`.
