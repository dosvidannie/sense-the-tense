# sense the tense

спокойная браузерная игра для тренировки английских времён на примерах из живых ситуаций.

доступны два режима: «карточки» и «лови ошибку». можно выбрать времена, темы и от 5 до 99 заданий. после партии игра показывает разбор ошибок, а на главном экране — сводку за последние семь дней.

прогресс и задания для повторения сохраняются только в браузере на текущем устройстве. новые недельные данные собираются с момента обновления; прежний общий прогресс сохраняется.

## запуск проекта

```bash
npm install
npm run dev
```

## проверка сборки

```bash
npm run build
```

## автономный html-файл

```bash
npm run build:offline
```

готовый файл появится в корне проекта под именем `Sense the Tense.html`.

## идея на потом

возможный выбор уровней языка от a1 до c1 и долей заданий разных уровней. сейчас задания остаются в общем диапазоне b1–b2: отдельного деления на b1 и b2 нет.
